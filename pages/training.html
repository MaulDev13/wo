Progressive Overload Rules

Type Rule
Compounds (bench, squat, deadlift, OHP, row) +2.5 kg when top of rep range hit across all sets
Isolation (laterals, curls, flies, extensions) +2 kg per 1–2 weeks
Pull-ups +1 rep to best set per month minimum
Weight jump feels too hard Add 1 rep instead, try weight again next session
After 2+ missed sessions Drop weight 10% before resuming — no ego loading
Exercise swapping Same 5–6 exercises per session for minimum 8 weeks
